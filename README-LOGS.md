# Диагностика MCP Hub 3.1

В панели откройте **Логи**. Там доступны фильтры уровня и источника, поиск, пауза/follow, просмотр полей записи и выгрузка JSONL.

Основной файл: `logs/hub.jsonl`. Он ротируется автоматически (до 2 МБ, три предыдущие копии). Токены, пароли, cookie и другие секретные поля маскируются перед записью.

Ошибки интерфейса (`window.onerror`, необработанные Promise), RPC, HTTP и переподключения SSE попадают в общий журнал. Для ошибки уровня `error` создаётся короткий `errorId`, который можно сопоставить с сообщением в интерфейсе.

Журнал вызовов MCP использует фиксированный скролл-контейнер и адресное обновление строк. Новые события не перестраивают страницу и не сбрасывают позицию прокрутки.
